## Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/ritesh-portfolio.git
```

Open the project directory:

```bash
cd ritesh-portfolio
```

Start a local server:

```bash
python -m http.server 5500
```

Open:

```text
http://localhost:5500
```

The portfolio can also be opened directly using `index.html`, but a local server is recommended for testing downloads and browser behavior.

## Deployment

This static portfolio can be deployed using:

* Vercel
* GitHub Pages
* Netlify
* Cloudflare Pages
* Any static web-hosting provider

### Vercel Deployment

1. Push the complete project to GitHub.
2. Sign in to Vercel using GitHub.
3. Import the portfolio repository.
4. Select **Other** as the framework preset.
5. Leave the build and output settings empty.
6. Click **Deploy**.

New commits pushed to the production branch will automatically trigger updated deployments.

## Update the Portfolio

After modifying the website:

```bash
git add .
git commit -m "Update portfolio"
git push
```

The connected Vercel project will deploy the update automatically.
